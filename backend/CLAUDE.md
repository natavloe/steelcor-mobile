# Стилкор — сервер (Laravel 13 + Filament 5)

Перед изменениями прочитайте `../docs/02-arhitektura/` — там модель данных, статусы и права.

Правила проекта:
- Статусы меняются только через сервисы (`OrderWorkflow`, `ProcurementService`, `RefundService`) и `setStatus()` — каждая смена пишется в историю.
- «Оплачен» — только по выписке банка (`bank_transactions` + `payment_allocations`), никогда по действию клиента.
- Закупочные цены, поставщики и маржа не попадают в клиентский API (`app/Http/Resources/Client`). В админке поля себестоимости не включаются в форму без права `costs.view` (скрыть недостаточно — Filament грузит данные скрытых полей).
- Принятое предложение не редактируется — только новая версия.
- Деньги считаются через `App\Support\Money` (без float).
- Тексты интерфейса — на русском. Тесты: `php artisan test` (PostgreSQL, база `steelcor_test`).
