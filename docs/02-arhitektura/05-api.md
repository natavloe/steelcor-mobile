# 5. Клиентский API

Статус: черновик. Точное описание (OpenAPI) будет генерироваться из кода.

## Принципы

- Базовый адрес: `https://<домен>/api/client/v1/`. Версия в адресе: старые версии приложения продолжают работать после обновлений сервера.
- Формат: JSON. Даты — ISO 8601. Деньги — **строкой** (`"125000.50"`), чтобы не терять копейки. Количество — строкой.
- Авторизация: токен (Laravel Sanctum) в заголовке `Authorization: Bearer …`. Каталог доступен без входа.
- Регион передаётся заголовком `X-Region: smr`.
- Текущая организация клиента: заголовок `X-Organization: <id>`. Сервер проверяет, что пользователь в ней состоит и имеет нужную роль.
- Списки: постранично, `?page=2&per_page=30`.
- Создание заказа принимает заголовок `Idempotency-Key`: повторная отправка при плохой связи не создаст второй заказ.
- Ошибки — единый формат:

```json
{ "error": { "code": "offer_expired", "message": "Срок действия предложения истёк", "fields": {} } }
```

- **Закупочные цены, поставщики, маржа и внутренние заметки не возвращаются ни одним методом.** Это проверяется автотестом.
- Внутренние этапы закупки клиенту показываются нейтрально: статус `procurement` отдаётся как `in_work` («Заказ в работе»), `supplier_confirmed` — как `supply_confirmed` («Поставка подтверждена»).

## Методы

### Справочники и каталог (без входа)

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/regions` | Активные регионы |
| GET | `/categories` | Дерево категорий |
| GET | `/categories/{id}/filters` | Фильтры категории со значениями |
| GET | `/products?category=…&q=…&f[grade]=…&f[diameter][min]=…&sort=…` | Поиск и список |
| GET | `/products/{id}` | Карточка: характеристики, единицы, цена и доступность в регионе |
| GET | `/products/{id}/convert?qty=2&from=t&to=m` | Пересчёт единиц |
| GET | `/pickup-points` | Пункты самовывоза региона |

### Вход

| Метод | Адрес | Что делает |
|---|---|---|
| POST | `/auth/otp/request` | Отправить SMS-код на телефон |
| POST | `/auth/otp/verify` | Проверить код → токен |
| POST | `/auth/logout` | |
| GET / PATCH | `/me` | Профиль, согласие на обработку ПДн |
| POST | `/me/push-tokens` | Зарегистрировать устройство для push |

### Организации и адреса

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/organizations` | Мои организации и роль в каждой |
| GET | `/organizations/lookup?inn=…` | Подсказка реквизитов по ИНН |
| POST | `/organizations` | Добавить организацию (статус «не проверена») |
| GET / PATCH | `/organizations/{id}` | |
| GET / POST | `/organizations/{id}/members` | Сотрудники, приглашение |
| GET / POST / PATCH / DELETE | `/addresses` | Адреса доставки текущей организации |

### Корзина и заказы

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/cart` | Корзина с предварительным расчётом |
| POST / PATCH / DELETE | `/cart/items[/{id}]` | |
| POST | `/orders` | Оформить заказ из корзины |
| GET | `/orders?status=active` | Мои заказы |
| GET | `/orders/{id}` | Заказ: 5 статусов, сроки, «нужно ваше действие» |
| POST | `/orders/{id}/repeat` | Положить состав в корзину |
| POST | `/orders/{id}/cancel` | Отмена (только до оплаты; после — заявка менеджеру) |
| GET | `/orders/{id}/offers` | Версии условий |
| POST | `/orders/{id}/offers/{offerId}/accept` | Принять условия |
| POST | `/orders/{id}/offers/{offerId}/request-changes` | Попросить изменить, с комментарием |
| GET | `/orders/{id}/invoices` | Счета и статус оплаты |
| POST | `/orders/{id}/payment-notice` | «Я оплатил» + файл платёжки (только сигнал) |
| GET | `/orders/{id}/documents` | Документы и статусы подписания |
| GET | `/documents/{id}/file` | Скачать PDF (временная ссылка) |
| GET | `/orders/{id}/shipments` | Отправления и события |
