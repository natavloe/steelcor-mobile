## 1. Подтверждение представителя компании — предложенная схема

Проверка ИНН и реквизитов уже есть. Дополнительно проверяется, что **конкретный пользователь** вправе действовать от имени организации (отметка на пользователя в каждой организации отдельно).

Способы подтверждения (менеджер выбирает в админке):
- **Руководитель по ЕГРЮЛ** — ФИО совпадает с выпиской, плюс звонок;
- **Звонок в компанию** — по официальному телефону (с сайта / из справочника), не по номеру из приложения;
- **Доверенность / приказ** — скан прикладывается;
- **КЭП через ЭДО** — после этапа 5.

Сохраняется: кто подтвердил, когда, способ, комментарий, файл. Подтверждение можно отозвать (уволился). Всё в журнале.

Для клиента: без подтверждения можно смотреть каталог, собирать корзину и отправлять заказ; **принять условия** (зафиксировать цену и получить счёт) — только подтверждённый представитель. Сотрудники, приглашённые подтверждённым владельцем, считаются подтверждёнными.

Открытый вопрос: запрещать ли неподтверждённым даже отправку заказа.
