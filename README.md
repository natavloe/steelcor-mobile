# Стилкор — платформа заказа металлопроката

Мобильное приложение (iOS/Android) и веб-админка для ООО «ГК «Стилкор»: каталог → заказ → согласование условий → счёт → оплата (по выписке банка) → закупка у поставщика → доставка.

| Папка | Что это |
|---|---|
| [`docs/`](docs) | Анализ (этап 1), архитектура (этап 2), [скриншоты](docs/screenshots) |
| [`backend/`](backend) | Сервер и админ-панель: Laravel 13 + Filament 5 + PostgreSQL |
| [`mobile/`](mobile) | Приложение: Expo (React Native) + TypeScript |

Запуск и проверка — в README каждой папки.
